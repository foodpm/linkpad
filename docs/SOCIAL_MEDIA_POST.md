# LinkPad 社媒发布文案

## 主文案（小红书 / 即刻 / 朋友圈）

收藏夹吃灰？链接发来发去总在过期？

做了个工具：LinkPad — 导航首页 + 链接仓库，二合一。

核心玩法是「关注 + 自动同步」：
创建一个链接仓库，把相关网站丢进去，分享给朋友或团队。对方关注后，仓库里的链接自动出现在 TA 的首页，你每次更新（加链接、删链接）都实时同步过去，不用再重复发送。

其他亮点：
- 新标签页直接变成你的导航首页（Chrome / Edge 扩展）
- 常用网站自动置顶，越用越顺手
- 分类和网站可单独加密，借电脑也不怕
- 粘贴链接自动抓图标，还有待办 / 股票小组件

发现页里已经有不少高质量仓库：设计导航、独立开发工具、产品经理工具箱……关注即可一键拥有同款。
