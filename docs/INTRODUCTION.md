# LinkPad 产品介绍

> 收藏好链接，分享好品味
>
> 在线体验：https://linkpad.site

LinkPad 是一个集「极简导航首页 + 社区链接仓库」于一体的效率工具。它解决两个高频痛点：常用网站散落在各个浏览器收藏夹里，找不到也理不顺；好链接想分享给别人，发一次链接就要重新发一次更新。

## 它能解决什么问题

- **收藏夹混乱**：工作、生活、学习的网站混在一起，想找的时候翻半天。LinkPad 把它们整理成一个干净的导航首页，新标签页打开即是入口。
- **分享低效**：把链接发给同事或朋友后，每次更新都要重新发送。LinkPad 的链接仓库支持「关注 + 自动同步」，关注一次，永远最新。
- **隐私顾虑**：工作后台、个人账号等不想被看到的收藏，可以单独加密，借电脑也不怕。

## 核心功能

### 链接仓库

链接仓库是 LinkPad 的灵魂功能。创建一个合集，把相关网站添加进去，一键分享给他人。仓库支持三种可见性：

- **公开**：任何人可访问、可关注
- **私密**：仅自己可见
- **密码保护**：凭密码访问，适合团队内部使用

最强大的是「关注 + 自动同步」机制：其他人关注仓库后，仓库里的链接会自动出现在关注者的导航首页。后续仓库有任何更新（新增、修改、删除），都会自动同步给所有关注者——只需关注一次，永远保持最新。

**典型场景**：产品经理创建一个密码保护的仓库存放需求文档和原型链接，开发同学关注后无需反复索要，打开首页就能看到最新版本。

### 个人导航首页

- **常用链接**：自动统计访问频率，最常访问的网站排在最前，越用越顺手
- **分类与网站加密**：单个分类或网站可独立设置密码，保护隐私内容
- **自动识别图标**：粘贴 URL 即可收藏，网站图标自动抓取，无需手动上传
- **本地搜索**：支持网络搜索和站内收藏搜索，收藏再多也能秒找
- **小组件**：内置待办事项、股票行情、黄金价格，导航页也是个人信息面板

### 浏览器扩展

提供 Chrome / Edge 扩展（Manifest V3），安装后每次打开新标签页自动进入 LinkPad——新标签页就是你的效率中心。

## 技术架构

| 模块 | 技术 |
| --- | --- |
| 后端 API | Cloudflare Workers + Hono |
| 数据库 | Cloudflare D1（SQLite） |
| 对象存储 | Cloudflare R2 |
| 前端 | React 19 + Vite + Tailwind CSS 4 |
| 浏览器扩展 | Chrome Extension（Manifest V3） |
| 认证 | JWT（HMAC-SHA256），密钥通过 Cloudflare Secrets 管理 |

整个应用部署在 Cloudflare 边缘网络上，无需自建服务器，全球访问都快。

## 快速开始

1. 访问 https://linkpad.site 注册账号
2. 在首页添加常用网站，或安装浏览器扩展将新标签页设为 LinkPad
3. 创建你的第一个链接仓库，分享给朋友或团队
4. 到发现页逛逛，关注感兴趣的仓库，一键拥有别人的整理成果
