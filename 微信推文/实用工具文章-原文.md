# 42 个实用工具，网址都在这了

收藏夹这东西，存的时候觉得以后一定会用，真到要用时又找不到。

这次把 LinkPad「实用工具」仓库里的站点逐个打开看了一遍，去掉打不开的，剩下 42 个，按图片处理、临时邮箱、综合资源、工作办公、文件传输、付费会员、其他工具分成 7 类。

下面写的是我实际看到的功能、有没有免费额度、要不要登录，不是照搬网站简介。网址只写到域名和必要路径，复制到浏览器就能打开。

## 01 图片处理（10 个）：从生成到套壳，日常够用

这一类用得最频繁。出图、修图、截图、套壳，基本都能在浏览器里解决。

- **造图局** — zaotu.vip
  国内可直连的 AI 生图、生视频站，聚合 GPT-image 2.5、Grok、Nano Banana 等模型，首页标注免费在线使用。适合临时出几张图，不想折腾 API 的时候。
- **Photoshop 在线版** — photoshop.adobe.com
  Adobe 官方网页版 Photoshop，图层、蒙版、调色等常规修图都能做。需要登录 Adobe 账号，免费额度有限，重度功能走订阅；临时改图比装客户端省事。
- **在线网页版 PS** — tugaigai.com/online_ps
  浏览器里运行的类 PS 编辑器，界面和快捷键贴近 Photoshop，能打开和保存 PSD、XCF、Sketch。免费、不用注册，处理在本地完成，图片不上传服务器。
- **DeviceShots** — deviceshots.com
  把一张截图套进手机、平板、笔记本或浏览器边框，导出高清展示图。内置 76 种设备和各社交平台尺寸模板，免费、不用注册，全程在浏览器里完成。
- **Dimmy** — dimmy.club
  给截图套设备外壳的在线工具，可选笔记本、手机、平板、桌面显示器，能改配色和背景，导出 PNG。免费、不用登录，个人和商用都允许。
- **PixPin** — pixpin.cn
  Windows 和 macOS 的截图工具，截图、标注、贴图、长截图、录屏、OCR 在一个软件里。基础功能免费，AI 翻译、表格和公式识别要会员；本地 OCR 不上传图片。
- **Mockup World** — mockupworld.co
  免费样机素材库，按 iPhone、MacBook、包装、海报等分类，提供 PSD 和在线 mockup 生成器。下载不用登录，但 PSD 要自己用 Photoshop 改；部分素材会跳到作者站点。
- **Sketchfab** — sketchfab.com
  全球最大的 3D 模型展示与交易平台，可在线预览、搜索并下载模型，覆盖建筑、角色、文物等分类。浏览免费，部分模型下载要登录，商用或高精度模型单独付费。
- **手写字文稿生成器** — vtool.pro/handwriting/index.html
  把输入的文字转成手写体图片或 PDF，支持多页和多种中英文字体。免费、不用登录，适合做手写作业、笔记截图一类的内容。
- **迅捷在线压缩** — yasuo.xunjiepdf.com/img
  在线图片压缩，支持 JPG、PNG、GIF、BMP，能按清晰度、目标体积或证件照尺寸压。免费、不用注册，一次最多 10 张、单张 100M；站内也在推客户端。

> 在线 PS 适合临时改图，长期用还是本地版稳；套壳时选和自己设备比例一致的模板，不然画面会变形。

## 02 临时邮箱（5 个）：只用来接一次验证码

注册试用、下载资料时不想暴露主邮箱，用这一类顶一下。全部免费，也都不要注册。

- **临时谷歌** — linshiguge.com → haoweichi.com
  打开原域名会跳到 haoweichi.com 的临时邮箱页，提供 Gmail 前缀地址，可换地址、自定义前缀、刷新收信。免费、不用注册；地址在共享池里，别用于重要账号。
- **22.do** — 22.do/zh/temporary-outlook
  临时 Outlook 和 Microsoft 邮箱生成器，随机分配 @outlook.com 地址，进入收件箱就能收验证码，到期自动删除。免费、不用注册，页面写明使用后自动清理。
- **EduMail** — edumail.su → edumail.bz
  生成 .edu 教育邮箱的临时邮箱站，原域名会跳到 edumail.bz。主打即时收信和自动提取验证码，免费额度之外有 Pro 套餐；适合需要教育邮箱注册的场景。
- **Temp Mail** — temp-mail.org/en
  老牌一次性邮箱，打开即分配地址，可复制、刷新、更换、删除，支持多语言和 App。免费版足够收验证码，Premium 去广告并延长保留时间。
- **Generator.email** — generator.email
  一键生成任意前缀和域名的临时邮箱，邮件直接显示在浏览器里，可自定义域名、设置来信提示音。免费、不用注册；地址公开可见，不要用来收敏感信息。

> 临时邮箱随时会失效，找回密码、接收账单都会断。只用来过一次验证，别拿它注册重要账号。

## 03 综合资源（7 个）：下载站与资源索引

软件、插件、电子书、音乐，属于「想起来才用，用一次省很多时间」的那类。

- **阿虚同学** — ahhhhfs.com
  个人维护的资源分享站，覆盖 AI 工具、开源项目、自托管软件和效率应用，文章里常带部署教程和真实使用场景。免费浏览，部分资源要跳转原站或注册。
- **麦克搜** — imacso.com
  Mac 软件下载与使用技巧站，按效率、设计、开发、系统工具等分类，提供版本更新和软件介绍。下载免费，部分软件是破解版，装之前注意来源和授权。
- **插件小屋** — chajianxw.com
  Chrome 插件国内下载站，提供 crx 离线安装包和安装教程，解决打不开 Chrome 应用商店的问题。免费、下载不用登录；插件版本可能滞后，注意核对更新。
- **爱资源** — iwyu.com
  博客型软件资源站，分享 Windows、macOS、Android 软件和系统镜像，也有教程和壁纸。免费下载，现在要用 QQ 登录；站内含破解软件，注意安全和合规。
- **无损音乐下载** — flac.music.hi.cn
  多站合一的音乐搜索与试听站，可搜歌、试听并跳转下载无损音频。免费、不用注册；资源来自第三方搜索，版权归原作者，只适合个人试听。
- **Z-Library 中转** — tboxn.com/sites/320.html
  Tbox 导航里的 Z-Library 介绍页，汇总最新可用地址和镜像，点「打开网站」再跳转过去。导航页免费；Z-Library 本身要注册才能下载，版权风险自担。
- **Obsidian 插件集市** — pkmer.cn/products/plugin/pluginMarket
  PKMer 建的 Obsidian 插件与主题索引，中文介绍、截图和使用说明齐全，解决官方市场访问慢的问题。免费浏览，配合 Pkmer Market 插件可以一键安装。

> 第三方下载站常见问题是捆绑安装、版本偏旧，装之前看清安装包内容；电子书和音乐注意版权。

## 04 工作办公（1 个）：这一类只剩一个，但每周都用

写周报这件事，能省十分钟就是十分钟。

- **周报生成器** — weeklyreport.avemaria.fun/zh
  输入几句工作内容，选模板后生成结构完整的周报，支持自定义模板和历史记录。免费、不用登录，记录只存在浏览器本地，生成走 OpenAI 接口。

> 别把客户名、未公开数据粘进去。页面自己也提示了，隐私内容不要上传。

## 05 文件传输（2 个）：不登录，传完就走

临时传个大文件，不想加好友、不想上传网盘时用。

- **QuickSend** — quicksend.chat
  局域网文件传输工具，同一 Wi-Fi 下扫码配对，电脑、手机、NAS 之间互传文件和剪贴板，不走外网。提供 Windows、macOS 客户端，无需登录；跨网络用不了。
- **Snapdrop** — snapdrop.net
  浏览器打开发送文件，另一台设备打开链接就能接收，不用装 App、不用注册。现在改成先上传再生成分享链接的方式，站点由 LimeWire 运营，适合临时传单个文件。

> 传完记得关页面。敏感文件别走第三方上传式工具，局域网直传更稳妥。

## 06 付费会员（2 个）：非官方渠道，自行判断

两个都是充值或代购渠道，省钱是真的，风险也是真的。

- **SEA GM** — seagm.com/zh-cn
  面向全球华人的游戏点卡、礼品卡和手游充值平台，支持 PayPal、信用卡和各国电子钱包。需要注册下单，价格随汇率和渠道浮动；卖的是充值码，不是账号。
- **MTCGAME** — mtcgame.com
  土耳其区 iTunes 礼品卡在线购买站，标注官方苹果代码、快速发货，可在土耳其 Apple ID 兑换。需要注册并选支付方式，按 TRY 结算；跨区充值有账号风险。

> 别把账号密码交给代充，也别一次囤太长周期。价格异常低的时候，先想想风险在哪。

## 07 其他工具（15 个）：杂项，但都是真会用到的

按使用场景分成三组：查信息、做小工具、下载与内容。

### 查信息 / 看数据

- **AppStorePrice** — appstoreprice.org/zh/apps
  App Store 各区应用和订阅的比价站，可浏览热门应用、对比不同区服价格。免费浏览，部分功能要登录；价格随汇率变动，下单前再核对一次。
- **AI Hot** — aihot.news
  数字生命卡兹克出品的 AI 资讯站，每天从全网筛出模型发布、新产品、论文和观点，AI 写摘要并打分去水文，另带热点榜和模型榜。免费、不用登录。
- **出海雷达** — lab.ytdeepsea.com/radar
  Gary 的 AI 视频情报站，每天早上 6 点扫 B 站、YouTube、抖音、TikTok、小红书、X 和 GitHub，挑出当天冒头的题材和新工具，每条附判断依据。免费浏览，还能接 MCP 给 Agent 查询。
- **IP 检测** — ip.skk.moe
  Sukka 做的 IP 检测页，打开显示当前出口 IP、归属地和线路信息，用来确认代理有没有生效。免费、不用登录；对自动化访问有验证码，正常浏览器打开没问题。
- **大盘云图** — dapanyuntu.com
  把 A 股、ETF、可转债和港股放在一张可缩放热力图上，面积代表市值、颜色代表涨跌，适合快速看板块轮动和权重股强弱。免费、不用登录，支持截图分享。

### 生成 / 小工具

- **美国地址生成器** — meiguodizhi.com
  随机生成美国地址、身份信息、信用卡号、电话和邮箱，也支持加拿大、日本、英国等地址。免费、不用登录；生成数据只能用于填表测试，不是真实身份。
- **上标文字生成器** — qiwangming.com/shangbiao
  把数字转成上标小字符，常用于昵称或电话号码展示，页面另附下标生成和相关符号。免费、不用登录，只处理数字。
- **在线字数统计** — mb5u.com/tool/zishutongji
  统计文本里的汉字、标点、字母、数字和总字符数，按中文 2 字符、英文 1 字符计算。免费、不用登录，适合检查文案长度和平台字数限制。
- **户型设计装修** — wy51ai.github.io/floorplan-3d
  浏览器里的 3D 户型编辑器，可拆改墙体、拖放家具、切换 2D 和 3D、模拟日照，能导出图片或方案 JSON。免费、不用登录，GitHub Pages 托管，装修前可以先自己摆一遍。

### 下载 / 内容

- **SaveTwitter** — savetwitter.net/zh-cn3
  推特（X）视频、GIF、图片和 MP3 的下载器，粘贴链接即可解析。免费、不用登录；公开账号的内容可用，私密或受保护内容不行。
- **HeroSMS** — hero-sms.com/cn
  虚拟号码接码平台，覆盖 180 多个国家、700 多个服务，按次付费，起价不到 1 美分。需要注册充值；号码会被重复使用，别拿来注册和真实身份绑定的账号。
- **水杉输入法** — msime.app/download
  开源输入法，输入中文时同步显示英文写法，适合学英语或对外交流。Windows、macOS、Linux、iOS、Android 都有版本，免费下载，安装包从官网或网盘获取。
- **WeduLab** — wedulab.com
  面向课堂的交互式教学工具集，物理电路、地理等高线、大气环流、地球运动等实验打开即用，可投屏也可让学生自己操作。免费、不用安装，部分功能可能要注册。
- **花束 Motion** — github.com/alchaincyf/huashu-motion
  GitHub 上的开源 skill，让 coding agent 直接生成产品宣传片，能配乐、按画面局部修改。免费开源，需要自己配 agent 环境，按 README 安装。
- **江山时序** — github.com/DeanChensj/jiangshan-map
  中国历史交互地图时间轴，覆盖公元前 403 年至今 18 个朝代、164 个疆域快照，还有地名沿革和诗词路线。开源免费，网页直接打开或本地部署。

> 接码平台涉及隐私和合规，别用来注册和真实身份绑定的服务；下载类工具注意平台规则。

## 08 怎么用这份清单

1. 先挑 5 个，不要全收藏。图片处理挑 2 个（在线修图 + 套壳截图），临时邮箱 1 个，文件传输 1 个，再按工作习惯补 1 个。收藏太多等于没收藏。
2. 用浏览器书签分组，别只放在微信收藏。微信收藏搜起来费劲，换设备也不方便。
3. 第三方站点先看域名、再看安装包，确认没问题再登录。尤其是下载站和代充类。
