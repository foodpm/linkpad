# LinkPad · Dark Tech Keynote

## Style

**Lemo-Opuscar · Dark Tech Keynote**（用代码做片，无视频模型）

- 近黑舞台 + 极细网格，唯一品牌强调色是 LinkPad 蓝。
- 界面本身是主角：光标、面板、卡片、状态都按节拍落位。
- 前 15 秒用光/扫光揭示，后段用小爆点与信息清理形成节奏对比。

## Beat map

| 节拍 | 时间 | 画面 | 口播 |
| --- | --- | --- | --- |
| hook | 0.0–3.2s | 散乱链接从噪点聚成品牌 Logo | 收藏夹太乱，链接太多，找东西总在翻页。 |
| home | 3.2–8.0s | LinkPad 首页展开；常用链接按频率排位，图标自动识别 | LinkPad 把常用网站整理成一屏导航，越用越顺手。 |
| repo | 8.0–14.4s | 创建产品经理常用工具仓库，关注后右侧自动同步 | 创建链接仓库，一键分享。别人关注一次，以后更新自动同步。 |
| quality | 14.4–20.0s | 粘贴 URL 触发重复提醒；失效链接弹窗被一键清理 | 粘贴链接时重复自动提醒，失效链接也能一键清理。 |
| preview | 20.0–24.4s | 悬停卡片弹出真实网站截图、标题与描述 | 悬停就能预览网站，先看内容，再决定打开。 |
| extension | 24.4–28.4s | 新标签页进入 LinkPad，搜索框聚焦 | 装上浏览器扩展，新标签页就是你的效率中心。 |
| widgets | 28.4–32.8s | 站内搜索秒出结果；待办、股票、黄金小组件滑入 | 收藏再多也能秒搜，还能加上待办、行情和小组件。 |
| logo | 32.8–38.4s | Logo、标语、网址与开源信息收束到暗色舞台 | LinkPad，收藏好链接，分享好品味。 |

## Rhythm

- Route：hybrid。连续光标叙事为骨干，quality / widgets 处加入快节奏 UI 爆点。
- Energy：7 → 6 → 8 → 7 → 9 → 7 → 8 → 4。
- Hook 在 3 秒内；quality 段的两个产品爆点在 15.2s / 18.4s；preview 是 hero 信息揭示。
- 每个场景边界至少换焦点与信息密度；扫光 / 蓝色 flood 负责接镜。

## Continuity chain

乱链接 → Logo → 导航面板 → 仓库卡 → 同步链接 → 质量徽标 → 预览卡 → 新标签页搜索 → 小组件 → 品牌收束。
